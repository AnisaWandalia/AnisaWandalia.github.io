Project Overview

This project is a facial recognition-based Two-Factor Autentication (2FA) system developed to enhance web application security. The system uses YOLO for face detection, ArcFace for facial feature extraction, and KNN for face classification.

The authentication process starts by accessing the device camera to detect the user's face and select the most optimal frame. The selected face is the processed to extract facial features into a numerical vector and classified against registered users. The web application was built with Laravel, with extracted feature vectors stored in a MySQL database.

Key Features

Real-Time Face Detection

Detect faces in real time through the device camera using YOLO and selects the most optimal frame for subsequent facial recognition processing.

Secure Feature Storage

Stores facial embeddings as numerical feature vectors in MySQL rather than raw video or facial images, providing a more efficient approach to managing facial recognition data.
